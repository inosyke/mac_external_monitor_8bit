# Виправлення режиму зовнішнього монітора на macOS

Утиліта `fix_external_display.py` використовує CLI BetterDisplay, щоб перемкнути зовнішній дисплей Apple silicon на сумісний 8-бітний режим з’єднання. Вона зберігає поточні SDR/HDR, кодування, діапазон та інші параметри, змінюючи лише бітність. Вбудований екран Mac не змінюється.

## Запуск

Потрібні Python 3, `displayplacer` для виявлення зовнішнього дисплея та CLI BetterDisplay із дозволеним доступом:

```sh
brew install displayplacer
python3 fix_external_display.py --dry-run
python3 fix_external_display.py
```

`--dry-run` лише показує команду, не перемикаючи дисплеї. BetterDisplay CLI може бути встановлений разом із застосунком або окремо через Homebrew. Якщо 8-бітний режим уже активний, утиліта нічого не змінює. Якщо немає сумісного 8-бітного режиму, вона завершується з помилкою, не змінюючи налаштувань.

## Автозапуск і автоматичне виправлення після підключення

Компілювати Python-скрипт не потрібно. Щоб перевірка запускалася при вході в macOS і повторювалася кожні 3 секунди, виконай:

```sh
python3 install_autostart.py
```

Для видалення автозапуску:

```sh
python3 install_autostart.py --uninstall
```

Агент не змінює налаштування, коли зовнішнього монітора немає або він уже в 8-бітному режимі. Інтервал у 3 секунди дає швидку реакцію після підключення, не запускаючи перевірку щосекунди. Помилки записуються в `~/Library/Logs/fix-external-display-error.log`.

## Важливо

`displayplacer` показує бітність framebuffer, яка може не збігатися з бітністю сигналу на кабелі. Утиліта використовує BetterDisplay `connectionMode` — той самий рівень режиму з’єднання, що й меню **Color Mode** на Apple silicon.

Утиліта спершу перевіряє, що BetterDisplay показує точний відповідник поточного режиму на 8 біт. Вона змінює лише `bpc:8`; кодування, діапазон, субдискретизація, роздільність і частота мають лишитися такими самими. Вона не змінює ICC-профіль.
